# Brechó Ammi Maju

Loja virtual construída com React e Vite. O catálogo permite pesquisar produtos e adicionar/remover itens do carrinho; o carrinho é preservado no navegador usando `localStorage`.

## Executar localmente

Requer Node.js 20.19+ ou 22.12+.

```sh
npm install
npm run dev
```

Para gerar e pré-visualizar a versão de produção:

```sh
npm run build
npm run preview
```

O catálogo e os contatos são dados de demonstração. O projeto não possui backend, estoque compartilhado nem processamento de pagamentos.
